# Job page refinement

Presentation-only follow-up for the job workspace:

- One full-width header contains the job title/status, client contact details and client-page actions. Client details are not repeated in Overview. Existing phone, email, map and edit affordances remain.
- Supported job actions use the quiet overflow icon. Back navigation is labelled Jobs and goes to the Jobs list.
- The three client-page actions stay available on every job tab; on phones they fill one row, with overflow separate.
- Plain text, 44px job tabs use a blue active underline, no icons, attention-only counts and normal document flow. Existing deep links and aliases remain intact.
- Overview starts with four shared KPIs, then a genuine linked next action when applicable and compact summaries. Quote value uses the saved ex-GST subtotal, without adding approved variations twice. Costs use the existing profitability hook’s confirmed inc-GST amount.
- Resolved variation-update banners are removed. At most one semantic-token notice is shown for a real action not already presented in the active view.

## Existing capability boundaries

This does not add archive/delete operations or rotation of the full client-project link. Archive remains explicitly unavailable. Existing quote-link regeneration and its confirmation remain in Quote; it is not relabelled as client-project link rotation. Existing duplicate and job-status handlers, client editing, secure preview/copy/send and their confirmations are preserved.

No server, schema, financial hook or integration changes were made.
